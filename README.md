# Proyecto Juego - El Gato (Tic Tac Toe)

## Descripción del proyecto

El presente proyecto implementa el Juego del Gato, también conocido como Tic Tac Toe. Es un juego de dos jugadores, X y O, que se turnan para marcar los espacios en una cuadrícula de 3x3. El jugador que logre colocar tres de sus marcas en una fila horizontal, vertical o diagonal gana el juego.

## Reglas del Juego

1. El juego se juega en una cuadrícula de 3x3.
2. Dos jugadores se turnan para marcar los espacios con X y O.
3. El primer jugador que logre alinear tres de sus marcas en una fila horizontal, vertical o diagonal gana.
4. Si todos los espacios están llenos y ningún jugador ha alineado tres marcas, el juego termina en empate.
